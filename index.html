⚙ AI 模型设置
使用你自己的 API Key。Key 只保存在本机，不会上传。患者信息发送前会自动脱敏。
❓ 怎么拿到 Key？点这里看 3 步教程
1. 手机浏览器打开 cloud.siliconflow.cn，用手机号注册（新用户送额度）
2. 登录后左侧点「API 密钥」→「新建密钥」→ 复制那串 sk- 开头的字符
3. 回到本 APP 的 ⚙ 设置，粘贴到上面「API Key」→ 点「测试连接」，成功后再点「保存设置」
注意：硅基流动需先完成「实名认证」，赠送额度才会到账；余额为 0 时用收费模型会报 402。
模型名不用手打：填好 Key 后点上面的「🔄 从账号拉取当前可用模型」，点一下即可填入。
识图模型请选带 VL 字样的（如 Qwen2.5-VL），需账户有余额。
提示：Key 只存在你手机里，不会上传到任何服务器。
当前使用的是硅基流动（支持网页直连）。也可以换成通义千问 / DeepSeek / 豆包。

🌸 使用说明
跟着这 5 步走，每天查房能省不少事
1️⃣
新建患者
点右下角橙色「＋ 新患者」。只需要填床号就能保存，其余可以后补。
2️⃣
让 AI 帮你填
在新建患者页点「📷 拍病历照片自动识别」，对着入院记录拍一张，姓名、性别、年龄、诊断、现病史会自动填好，核对一下再保存。
3️⃣
填 CARE LIST
点患者卡片 →「＋ 填写今日 CARE LIST」。逐项点「正常 / 异常」，异常项补充一句描述，很快就能过一遍。
4️⃣
生成查房记录
填完后点「🩺 AI 生成查房记录」，会自动写成病程记录初稿，可以复制粘贴到病历系统，也可以下载 Word。签名前请自己核对。
5️⃣
存医嘱模板和文献
底部「📚 文献库」可以按分类存放，支持直接导入 Word（.docx）文件，点开就是大字号阅读。
🤖 怎么接入大模型？
右上角 ⚙ → 选「硅基流动」→ 填 API Key → 点「测试连接」→ 保存。
Key 获取：手机浏览器打开 cloud.siliconflow.cn 注册（送额度），左侧「API 密钥」新建并复制。
没配置也能正常用，只是拍照识别和 AI 写病历用不了。
